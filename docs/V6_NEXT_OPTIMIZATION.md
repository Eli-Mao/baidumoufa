# V6后续优化潜力与建议预算（本轮不执行长搜索）

本轮对31015.978086分稳定V6的固定计划及原531432窗口做24.57秒静态扫描，附单候选全区间物理检查，不传播全目标轨道，不开发V7。扫描版本/结果见remaining_v6，计划SHA与封存CSV一致。

剩余中优2285、低优3728，全部仍有缓存窗口。中优119、低优776颗各自至少有一个能直接插入当前固定计划、通过完整物理检查的候选；中优2166、低优2950颗的所有缓存窗口在当前固定站点计划下被阻塞，不能据此认定全局不可安排。另2颗低优有几何空隙但有限候选未通过物理检查。全部窗口有5294段几何空隙，4624段属于未覆盖目标。

这些895个单目标机会高度重叠。按候选窗口并集与站点切换边界计算，在完全不动旧任务的条件下，最多再放**58项120秒任务**的资源放松上界；这不是58项可行计划。即使忽略冷却、目标连续窗口和真实优先级、把每个空隙都当成权重5，新增分数资源上界约**198.247分**。本轮所有空隙均不足240秒且每个不足270秒，只能容纳至多一项120秒任务，所以该宽松分数界按每段最长≤240秒计。超过4045颗总覆盖（3987+58）不能仅靠固定计划的直接填空完成，必须移动/替换旧任务；既有4100备选已经展示了这种取舍可行。

找到520个有阻塞任务、仍有正收益且候选物理通过的目标替换机会。例：站3任务2168低优得分1.2566406267，可被中优11736的240秒任务替代，净增1.7433593733；站6任务4052可替换成49279，净增1.5980468733。不同候选共享阻塞任务，不能累加收益。更大多任务交换的新收益尚未搜索；原最佳试验9次已接受重排贡献34.825781分、最大24项旧任务，提供机制证据，但不是对新V7改进幅度的保证。

预算证据：同一封存V5起点，V6均值从12秒30813.936068升到36秒31011.169323，增加197.233255分。最佳36秒试验最后6秒仍增加32.142188分，尚不能证明已饱和；但这不等于从最佳V6再加24秒就会获得相同增益。

建议先完成团队授权/PR合并和官方口径确认。之后先在**相同最佳V6起点**比较现有V5/V6继续优化，各30秒，seed44/55/66：6次搜索共180秒，另留6次完整审计约9–15分钟；保存得分/覆盖非支配方案。确认实际均值或有用的非支配边界提升、全部合法后，再用相同种子扩到60秒，不把不同预算最高分直接比较。需要覆盖导向研究时另设覆盖备选共同起点，单独报告，不混入得分起点对照；不修改冻结最终Evaluator。

性能方向：优先缓存窗口可行空隙及物理失败边界、针对短剩余区间筛候选、批量排序、复用物理引擎对象；每个接受任务仍需全区间物理检查，最终最优仍完整独立复核。当前36秒V6平均流程135.14秒（含约90秒最终审计），峰值RSS267.39MiB；优化器本身已不是唯一耗时来源。可以研究审计对象复用或并行，但不能因此省略端点、缩疏1秒网格或把内部oracle当作独立证书。以上仅建议，本轮没有执行这些新优化。
