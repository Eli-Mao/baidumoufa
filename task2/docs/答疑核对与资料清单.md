## 已重新准备的工程部分

1. 将连续相机视场与完整区域边界相交作为新的区域访问核，输出逐星实际接触区间；0.1° 网格只作历史对照。
2. STK 建场景脚本采用三个 AreaTarget，明确 `Any` 部分可见、传感器视场与视线约束。逐个 Sensor→AreaTarget 计算，并输出每一星、每个组成部分的访问和执行状态。
3. `summarize_stk_region.py` 检查所有星×区域组成部分是否真的计算，再同星合并重叠区间。缺输出不会误报成零访问。
4. `engineering_run.py` 已于 2026-11-10 升级为固定参数的 Python/STK 完整验证入口，输出到新的时间戳目录；总结果为 `verification_summary.json`。`out/qa55_n28/` 与 `out/engineering_n28/` 保留为历史近似结果。当前方法和证据见 [工程验证说明](轨道与STK工程验证.md)。
